# Книжный магазин
## В документации описаны методы и сущности требующие пояснения по использованию
### Архитектура
1. В классе datasource лежат коллекции с тестовыми данными
2. Слой dao достает от туда нужную информацию
3. Слой сервисов принимает объекты классов dao и использует их для обращения за данным к классу Datasource и внутри сервисов как раз и проводится много логики

### Сущности
 1. **ShopBook**  
 Эта сущность представляет собой отдельную сущности для маппинга ManyToMany сущностей Shop и Book   
 2. **WarehouseBook**  
 Эта сущность представляет собой отдельную сущности для маппинга ManyToMany сущностей Warehouse и Book 
3. **Status**  
Статус это перечисление для определения статуса онлайн заказа

### Service
1. **ShopService**
- в методе  
public void distributeBooks( Integer bookId, List<Integer> shopIds, Integer warehouseId, Integer amount)  
книги распределяются таким образом: сначала количество книг делится на всех одинаково и остаток от деления отправляется в первый магазин в списке List<Integer> shopIds
2. **WebShopService**
- метод public void cancelOrder(Integer orderId) кроме того что меняет статус заказа на отмененный отправляет книги обратно на склад
3. **WarehouseService**
- метод public Set<Book> findAllBooks(Integer warehouseId)  
сначала находит все записи в сущности WarehouseBook с id warehouseId и затем делает маппинг
на объеты книг по id книг

# Книжный магазин
## В документации описаны методы и сущности требующие пояснения по использованию
### Архитектура
1. **Слой repository** - все репозитории реализуют интерфейсы JpaRepository и поэтому имеют много 
готовых методов, также были добавлены собственные методы в некоторые репозитории. Для репозиториев
написаны тесты.
2. **Слой service** - часто принимают и возвращают dto, иногда малое количество параметров
например какой-то айди. Для сервисов написаны тесты. Также есть "базовые" сервисы и сервисы
"менеджеры" - с припиской Manager в названии класса. Отличие в том, что базовые имеют в 
своей зависимости только свою репозиторию, а менеджеры и другие сервисы. Это может быть полезно,
чтобы избежать циклических зависимостей.
3. **Слой controller** - REST контроллеры, принимают dto из JSON, параметры запроса или 
переменную пути и отдают и отдают их сервисам и затем если требуется возвращают ответ от
сервисов в виде JSON. Для демонстрации правильной работы контроллеров при проверке работы 
в них самих прописаны System.out.println(..) чтобы можно было увидеть результат. Также
и мои комментарии. Все curl которые могут понадобиться лежат в файле curls, они написаны 
для powerShell.
Данные инициализируются из sql скрипта data.sql

### Сущности - опишу не все, а которые требуют пояснения
1. **StorageGood**  
Эта сущность представляет собой отдельную сущности для маппинга ManyToMany сущностей Storage и Good   
2.  **Good**
Абстрактный класс товара, пока товары это только Book 
3. **Storage**
Абстрактный класс хранилища - склада или магазина
4. **Bill**  
Сущность чека, важно что по логике магазина она должна существовать всегда даже если заказ удален.
5. **OrderStatus**  
Статус это перечисление для определения статуса онлайн заказа (если покупка произошла в офлайн
магазине то статус автоматически FINISHED и выписывается чек)


### Service - опишу managers, потому что другие в основном только ищут все записи или по id
1. **AbstractShopManager** - дает доступ наследникам к общей логике
- метод **createOrder** создает сущность заказа и уменьшает количество товаров
в определенном складе
- метод **returnGoods** предоставляет логику для возврата заказа, увеличивает количество
товаров в том магазине где был получен чек и на чеке делает отметку, что
товары вернули
- **findStorageGood** - может понадобится в будущем
2. **ShopManagerService** наследуется от AbstractShopManager
- метод **sellGoods** делает заказ и выписывает чек
- **distributeGood** распределяет определенный товар из определенного склада по
списку магазинов
- метод **findBooksInShopByGenreAndAuthor** ищет книги которые есть в наличии в 
определенном магазине по данному жанру и данного автора
3. **WebShopManagerService** наследуется от AbstractShopManager
- метод **createOrder** создает заказ
- метод **cancelOrder** отменяет заказ, приписывает соответствующий статус заказу
и возвращает товары на склад из которого они приехали
- метод **changeOrderStatus** - метод для работников службы доставки, например заказ прошел сборку
и переходи в состояние TRANSIT - в пути
- метод **takeAwayOrder** - работник когда клиент забрал заказ в магазине производит операциб=ю
и выписывается чек и заказ переходи в стадию FINISHED
- метод **findBooksByGenreAndAuthor** поскольку это интернет магазин ищет по всем книгам
которые присутствуют в базеданных с данными автором и жанром
### Controller - REST контроллеры
 - **OrderRestController** позволяет найти заказ по id
 - **ShopManagerRestController** - предоставляет эндпоинты для продажи товаров,
распределения товара по магазинам, возврата товара и просмотра какие 
есть книги в магазине и также просмотра списка магазинов или поиск магазина 
по id
 - **ShopRestController** - предоставляет функционал по нахождению всех магазинов
или нахождению магазина по id - например если фронт энду понадобится
показать пользователю список всех доступных магазинов
 - **StorageGoodRestController** позволяет получить количество товара в 
определенном хранилище
 - **UserRestController** позволяет найти пользователя по id вместе с его заказами, 
посмотреть информацию об аккаунте, изменить информацию об аккаунте, зарегистрировать 
пользователя удалить пользователя
 - **WebShopManagerRestController** позволяет создать заказ, отменить заказ, 
изменить статус заказа, забрать заказ, вернуть товары, посмотреть все книги 
определенного автора и жанра

powerShell curl команды для запросов находятся в файле curls.txt
